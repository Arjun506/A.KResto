# Phase 29G — Pilot Staff Quickstart Guide

This quickstart guides operational staff through POS and KDS workflows.

---

## 1. Cashier POS Workflow

1. Open POS page.
2. Select table or input takeaway order.
3. Click items to add to cart.
4. Select modifiers if applicable.
5. Click **Checkout** and select Payment Mode.
6. Print/Reprint receipt.

---

## 2. Kitchen KDS Workflow

1. Open KDS screen in kitchen.
2. New orders appear as tickets instantly.
3. Click **Accept** ➔ **Preparing** ➔ **Ready** to update status.
