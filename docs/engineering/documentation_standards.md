# Engineering Standard: Documentation Standards

## 1. Documentation Organization

- Keep all core specs organized under `docs/` with sub-folders grouping specifications, design-system tokens, and operations guidelines.
- Place user journeys and visual layouts in `docs/ux/` or module folders.
- Store context information in `ai-context/` to maintain continuity between calls.

## 2. Document Quality Rules

- **No Placeholders:** Document entries must be complete. Avoid utilizing `TODO` markers, empty files, or placeholder summaries.
- **Markdown Linting:** Enforce valid headers, formatting rules, and list spacing in markdown files.
- **Authoritative Source:** Ensure any changes to APIs, database schemas, or permission roles are immediately documented.
