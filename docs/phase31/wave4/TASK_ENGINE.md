# Phase 31 Wave 4 — Task Engine

---

## Universal Task Execution Engine

- **Task Model**: Supports task creation, assignment, due date, priority (`LOW`, `NORMAL`, `HIGH`, `URGENT`), and checklist items (`src/workflow-foundation/task-engine/`).
- **Proof of Work**: Allows workers to attach proof of work metadata (photo attachment URL, completion note, location tag).
- **Incident Reporting**: Workers can submit operational issue reports with severity and context references.
