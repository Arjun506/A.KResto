# Project

## Current Vision

- Restaurant SaaS platform being redesigned into a next-generation **Business Operating System (Business OS)**.

## Current Tech Stack

- Backend: Node.js + NestJS + Prisma + PostgreSQL + Socket.io
- Frontend: Next.js (App Router) + React + Tailwind + Axios + Recharts + Lucide + socket.io-client

## Current Status (high-level)

- Frontend has role-based dashboards and redesigned login.
- Backend exposes NestJS modules including Auth and Orders with tenant and role guards.
- Dashboard pages are currently mock-data heavy (at least billing/kitchen/waiter pages).
