# Platform Glossary

This document defines core terminology used in **AK Business OS** documentation.

## Core Terms

- **Tenant:** A single corporate customer or business entity. Tenants own users, orders, settings, and billing configurations.
- **Capability:** A distinct, self-contained business module (e.g. POS, CRM, Inventory, Payroll). Capabilities can be dynamically enabled or disabled per tenant.
- **Industry Pack:** An industry-specific template of configuration settings, custom schemas, and page modifications (e.g. Restaurant Pack, Retail Pack).
- **Business Engine:** The foundational runtime environment that handles multi-tenant isolation, authorization, validation, and capability registration.
- **Developer Platform:** Reusable APIs, webhooks, and SDK setups that allow third-party developers to extend core capabilities.
- **Unified AI Engine:** Automated tool chains that run business forecasting, data analytics, and natural language dashboard interfaces.
