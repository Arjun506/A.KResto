## Universal Customer Application Blueprint

AK Customer OS provides a unified consumer experience across multiple commercial verticals:

### Primary Mobile Navigation (Wave 1 Universal Shell Config)
- `Home`: Personalized discovery hub, universal search, category grid, and active offers.
- `Explore`: Multi-vertical provider discovery (Food, Shopping, Rides, Hotels, Salons, Healthcare, Home Services).
- `Activity`: Universal Activity Timeline tracking active & past transactions across all verticals.
- `Chat`: Contextual messaging with businesses, drivers, delivery partners, and support representatives.
- `Profile`: User preferences, saved addresses, reward balances, privacy controls, and security settings.
