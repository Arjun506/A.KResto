## 1. Design System Overview

AK Business OS 2035 utilizes a unified, responsive design system engineered for multi-tenant enterprise intelligence applications across Web, Mobile, and Embedded Operational surfaces (POS/KDS/Mesh terminals).

### Key Architectural Guidelines
- **Unified Component Tokens**: Shared visual primitives in `@business-os/ui` handle typography, buttons, inputs, tables, badges, cards, metrics, and standard application states.
- **Color Palette & Contrast**: Native HSL CSS variables bind light and dark theme modes with high-contrast accessibility compliance.
- **Responsive Layout Grids**: Mobile-first flexbox and dynamic CSS grid containers scaling from single-column mobile drawers to multi-column operational displays.
