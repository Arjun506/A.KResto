# Phase 30 Wave 1 — Responsive Standard

---

## Breakpoints & Adaptive Layout Guidelines

| Device Class | Breakpoint | Target UX Surface | Layout Strategy |
| :--- | :--- | :--- | :--- |
| **Mobile** | `< 640px` | Customer App / Worker Task Queue / KDS | Single column flex, bottom navigation, sheet drawers |
| **Tablet** | `640px - 1024px` | POS Terminal / Housekeeping Board | Collapsible sidebar, 2-column grid cards |
| **Desktop** | `1024px - 1440px` | Universal Business Console / Admin | Fixed left sidebar, multi-column dashboard grid |
| **Large Displays** | `> 1440px` | Owner Command Center / Logistics Dispatch | 4-column executive metric grid, split pane views |
