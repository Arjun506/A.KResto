## Universal Workforce Shell Blueprint

AK Worker OS provides an execution-oriented interface for internal business employees across all industry verticals:

### Primary Mobile Navigation
- `Today`: Active shift status, current assignment, urgent tasks, and team updates.
- `Tasks`: Universal task engine list with priority filters (`URGENT`, `HIGH`, `NORMAL`, `LOW`).
- `Activity`: Personal work execution timeline.
- `Chat`: Contextual role-based chat with managers and team members.
- `Profile`: Work schedule, shift rosters, and safety guidance.
