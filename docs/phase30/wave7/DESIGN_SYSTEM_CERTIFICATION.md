# Phase 30 Wave 7 — Design System Certification

## Design System & Primitive Reusability Audit

All pages across `apps/web/` consume standardized design tokens and UI primitives from `@business-os/ui`:

- `MetricCard` (KPI indicators with trend arrows)
- `EmptyState` (Guided empty state graphic & call to action)
- `ErrorState` (Failure card with retry button)
- `OfflineState` (AK Connect connectivity banner)
- `PermissionDenied` (RBAC access restriction state)
- `UpgradeRequired` (Subscription tier entitlement barrier)
- `GlassContainer`, `AnimatedButton`, `Badge`, `Alert`
