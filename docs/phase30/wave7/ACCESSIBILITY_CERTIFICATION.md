# Phase 30 Wave 7 — Accessibility Certification

---

## Accessibility Audit Checklist

- **Semantic HTML**: HTML5 semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) used across all pages.
- **Form Association**: All form `<label>` tags explicitly associated with input controls using `htmlFor` / `id`.
- **Keyboard Traps**: Modal dialogs and command palette (`Ctrl+K`) handle `Escape` key close and maintain focus trap.
- **Color Contrast**: AAA compliant WCAG text contrast across light and dark modes.
- **Touch Target Sizes**: 44px minimum touch targets on mobile viewports.
