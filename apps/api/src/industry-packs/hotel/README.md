# Hotel Industry Pack Reference Implementation

This module provides hotel-specific property, room, checkin, housekeeping, and access management services. It integrates directly into the AK OS Core Platform (Epics 1-17) and serves as the second official certified Industry Pack.

## Bounded Contexts
1. **Property Management**: Configures buildings and wings layouts.
2. **Room Management**: Configures room types, amenities, and status checks.
3. **Reservations**: Walk-ins and OTA booking sync integrations.
4. **Housekeeping & Maintenance**: Tracks cleaning tasks, inspections, and maintenance work logs.
5. **Access control**: Issues digital key card codes.
6. **Analytics**: Computes ADR and RevPAR occupancy rates.
