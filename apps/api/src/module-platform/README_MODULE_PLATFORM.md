# Module Platform (Sprint 2 – Milestone 2A)

This folder contains the early-stage **Module Platform** implementation skeleton:

- Module registry (metadata)
- Dependency resolver (deterministic DFS)
- Tenant module state persisted via `tenant_features`
- Module lifecycle service (install/uninstall/enable/disable/update)
- Controller endpoints for installed modules, sidebar items, and widget exposure

Note: This is the initial scaffolding; it currently has placeholder implementations for:

- permission syncing and feature flag resolution
- subscription/industry gating

Follow TODO_SPRINT2_M2A_MODULE_PLATFORM.md for completion checkpoints.
