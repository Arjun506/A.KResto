# Pending Features

The following features are scheduled for development:

## 1. Core Platform Architecture

- **`libs/` Workspace Setup:** Scaffolding libraries for modular capabilities.
- **Capability Registry Database Model:** Adding prisma models to toggle active capabilities per tenant.
- **`FeatureGuard` & `TenantGuard` Merging:** Aligning request auth blocks under unified modular middleware.

## 2. Business Dashboards

- **Waiter Panel Dashboard:** table maps, active orders tracker, serving updates (GREEN color scheme).
- **Owner Admin Dashboard:** aggregated analytics, reservation lists, feedback log, and configuration panel.
- **Tenant Setup Wizard:** Multi-step onboarding experience to register businesses, select active industry packs, and load seed parameters.

## 3. General Capabilities

- Generic CRM, POS, Inventory, HRMS, and Payroll configurations.
- Industry Packs: Retail, Salon, Hotel, and Healthcare template overrides.
