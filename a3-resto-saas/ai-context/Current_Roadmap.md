# Current Roadmap

This roadmap establishes the timeline and phases for the transition to **AK Business OS**.

## Phase 1: Architectural Definition (Active)
- **Goal:** Complete a comprehensive documentation sweep and define code rules, design tokens, and modular specifications.
- **Deliverable:** 100% Documentation and Architecture readiness.

## Phase 2: Core Capability Migration
- **Goal:** Scaffold `libs/` directory, write NestJS dynamic registers, create `FeatureGuard`, and release the core generic `BusinessEntity` table.
- **Deliverable:** Transition from `Restaurant` monolith models to dynamic capability-based structures.

## Phase 3: Platform Integration & Launch
- **Goal:** Complete CRM, POS, HRMS, and Payroll configurations. Establish the developer platform API structures and release the AI assistant models.
- **Deliverable:** Production-grade modular platform supporting the SaaS Marketplace.
