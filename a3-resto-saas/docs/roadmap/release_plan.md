# Roadmap: Release Plan

This document outlines target deployment releases.

## Release v1.0.0-beta.1 (Sprint 4)
- **Features:**
  - Multi-tenant isolation engine (`TenantGuard` and database filters).
  - Capability dynamic registration and feature authorization flags.
  - Legacy Restaurant module migrates into Industry Pack #1.
- **Target Audience:** Internal validation teams and sandbox accounts.

## Release v1.0.0-rc.1 (Sprint 7)
- **Features:**
  - Marketplace framework (app registrations and subscription checkout pipelines).
  - Standard SDK modules for developers.
  - Retail Pack #2 and Salon Pack #3 overrides active.
- **Target Audience:** Beta test partners.

## Release v1.0.0 General Availability (Sprint 10)
- **Features:**
  - Production-ready core.
  - AI Analytics queries active.
  - Full Marketplace launch.
