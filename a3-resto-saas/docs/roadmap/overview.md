# Roadmap Overview

This roadmap defines the implementation schedule for **AK Business OS**.

## 1. Execution Phases

- **Phase 1: Architecture & Specs (Current):** Draft design docs, coding rules, engineering handbooks, and specifications for all 25 modules to prevent code overlap.
- **Phase 2: Core Engine Refactoring:** Scaffold the `libs/` directory structure, implement `FeatureGuard` for capability checking, and release the core dynamic `BusinessEntity` schema.
- **Phase 3: Core Module Implementation:** Build and migrate the POS, Inventory, and CRM modules to the dynamic core capabilities framework.
- **Phase 4: Ecosystem Enablement:** Release Developer SDKs, open public endpoints, and launch the Marketplace for third-party industry packs.

## 2. Milestone Deliverables

- **Milestone 1:** 100% Documentation and Architecture Readiness.
- **Milestone 2:** Release of the multi-tenant Capability Registry engine.
- **Milestone 3:** Migration of the legacy Restaurant dashboard and POS into the new capability modules.
- **Milestone 4:** Multi-Industry Pack beta release (Retail, Salon, Hotel).
