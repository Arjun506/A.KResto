# Roadmap: Product Backlog

This backlog catalogs feature stories scheduled for future implementation iterations.

## Core Backlog Items

### 1. Unified Tenant Setup Wizard
- **Story:** As a new business tenant, I want a step-by-step registration interface so I can select my industry pack and configure timezone, locales, and initial roles.
- **Priority:** High
- **Estimate:** 3 days

### 2. NestJS Generic FeatureGuard
- **Story:** As a system administrator, I want API endpoints shielded by dynamic feature guards so that tenants can only access capability modules matching their active licenses.
- **Priority:** High
- **Estimate:** 2 days

### 3. POS Terminal Checkout Refactoring
- **Story:** As a store cashier, I want to use a unified point-of-sale layout that syncs with generic product catalog databases and records inventory updates upon transactions.
- **Priority:** Medium
- **Estimate:** 5 days
