# .AI Documentation Root

This directory contains all AI‑related rules, prompts, templates, and personality definitions that guide the autonomous agents working on **AK Business OS**.

- **README.md** – Overview of the AI subsystem.
- **AI_Rules.md** – High‑level behavioral constraints.
- **Coding_Rules.md** – Coding style, linting, and safety.
- **Design_Rules.md** – UI/UX design conventions.
- **Architecture_Rules.md** – How AI should interpret and validate architecture.
- **Review_Rules.md** – Peer‑review and quality‑gate guidelines.
- **Memory_Rules.md** – What information the AI should retain between sessions.
- **Prompt_Library.md** – Re‑usable prompts for common tasks.
- **Agent_Personalities.md** – Role‑based persona definitions.
- **Templates/** – Boiler‑plate markdown templates for documentation, specs, and tickets.
