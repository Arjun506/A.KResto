# Technology Stack

This document catalogues the active technology stack for **AK Business OS**.

## 1. Backend (NestJS Monolith)

- **Framework:** NestJS
- **Language:** TypeScript
- **ORM:** Prisma Client
- **Database:** PostgreSQL
- **Security:** Passport JWT authentication, RolesGuard, and bcrypt encryption

## 2. Frontend (Next.js Application)

- **Framework:** Next.js (13+ App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, next-themes
- **Animations:** Framer Motion
- **State Management:** Zustand

## 3. DevOps & Environment

- **Task Orchestrator:** Turborepo
- **Containerization:** Docker, Docker-compose
- **Package Manager:** npm
