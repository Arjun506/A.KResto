# AI Templates

This directory houses templates for writing files in the **AK Business OS** project.

## 1. Documentation Template (`docs_template.md`)

```markdown
# [Title]

## Overview
[Detailed context and business objective]

## Requirements
[List functional and non-functional requirements]

## Specifications
[Endpoints, schemas, interfaces]

## Implementation Timeline
[Tasks and sprints]
```

## 2. API Endpoint Specification Template (`api_template.md`)

```markdown
# [Endpoint Title]

## Request Model
- URL: `[Method] [Route]`
- Headers: `Content-Type: application/json`
- Body Schema: `[DTO Name]`

## Response Model
- Success Code: `200/201`
- Payload Schema: `[Response Model]`
```
